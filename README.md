# Wedding invitation — 18 August 2027

A responsive editorial-style wedding invitation microsite.

## Preview
After GitHub Pages is enabled, the site will be available at:
https://mralexgov.github.io/s/

## Temporary content
All names, venue, schedule, phone number and RSVP destination are fictional placeholders and must be replaced with confirmed details before sending invitations.

## Files
- `index.html` — page structure and copy
- `style.css` — responsive styling
- `script.js` — countdown

## Publish
The workflow in `.github/workflows/pages.yml` deploys the root of the repository to GitHub Pages on pushes to `main`.
